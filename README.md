# NightScope Backend

Downloads for NightScope Backend (Windows). The app needs a Discord sign-in with a role in the NightScope Discord server.

## 1. Install the app

**[Download the newest installer](https://github.com/Resell-Tracker/nightscope-releases/releases/latest)** (the file named `NightScope-Backend-Setup-…exe`).

- Windows may show "Windows protected your PC". Click **More info**, then **Run anyway**.
- Open the app and press **Sign in with Discord**.
- The app updates itself: when a new version is ready it asks you to restart.

## 2. Optional: the FUTBIN helper (for "Popular" in Trending)

Everything works without it except the **Popular** list in Trending.

**[Download NightScope-FUTBIN-Helper.zip](https://github.com/Resell-Tracker/nightscope-releases/raw/main/NightScope-FUTBIN-Helper.zip)**

1. Unzip the folder somewhere it can stay, for example Documents.
2. In Chrome, open `chrome://extensions`.
3. Switch on **Developer mode** (top right).
4. Press **Load unpacked** and choose the `NightScope-FUTBIN-Helper` folder.

Keep Chrome open while you use Trending. The helper only reads FUTBIN pages for the app on your PC; it does nothing with your EA account.
